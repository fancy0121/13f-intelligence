# 13F 机构持仓看板 - 用户指南（给完全不懂代码的人）

这份指南教你：打开看板、查机构、查股票、维护自己的持仓、更新最新 SEC 数据、以及关闭看板。
你**不需要**会 Python、命令行或数据库。

---

## 一、怎么打开看板

**第 1 步**：打开 `13f-intelligence` 文件夹（就是本项目文件夹）。

**第 2 步**：双击文件 **`START_13F_DASHBOARD.bat`**
（也可以双击中文名文件 **`双击打开13F看板.bat`**，效果一样）。

**第 3 步**：等几秒钟，你的默认浏览器会自动打开一个页面，网址是：

```
http://localhost:8501
```

页面标题是「13F 机构持仓情报系统」。

> 提示：那个黑色的小窗口（终端）不要关，它是看板的后台。关闭它 = 关闭看板。

**第一次使用前需要装环境吗？**

- 如果双击后看到「Streamlit is not installed」或「Python was not found」，
  说明这台电脑还没装运行环境。请先安装 Python 3.11 或更新版本，然后打开一个
  命令行窗口，进入本文件夹执行：

  ```
  pip install -e .[dev]
  ```

  只需做这一次。之后正常使用都只要双击 `START_13F_DASHBOARD.bat`。

## 二、每个页面是干什么的

### 总览（Overview）

打开看板先看到这一页。它告诉你：

- 你现在看的是哪一季度的数据（例如 2026-06-30）和 filing 日期（例如 2026-08-14）。
- 多少家机构已更新、多少家陈旧、有多少修订。
- 本季度有多少 NEW / ADD / REDUCE / EXIT 事件。
- 数据质量状态（未解析证券、冲突等）。

> 请特别记住：**报告季度 ≠ 实时持仓**。13F 允许最长 45 天延迟。

### 机构（Managers）

选择一家机构（例如 Berkshire Hathaway），即可看到：

- 它最新一次披露的时间信息。
- 最新季度的新增（NEW）、增持（ADD）、减持（REDUCE）、退出（EXIT）清单。
- 它的 Top 持仓。
- 有没有连续多个季度同向的动作。

### 证券（Securities）

输入 Ticker（如 GOOGL）、CUSIP（如 02079K305）或发行方名称（如 Alphabet），即可看到：

- 身份信息（发行方、CUSIP、解析状态）。
- 数据新旧。
- 哪些机构持有它，各自是增持还是减持。
- 增持/减持/退出计数、连续两个季度同向的机构数、历史时间线。

如果搜索出现多个候选，请手动选择正确的证券，系统不会替你乱选。

### 活动探索（Activity Explorer）

按「多少家独立机构报告了 NEW / ADD / REDUCE / EXIT / 重复增持 / 重复减持」对证券做
**中性排序**。这里只是事实排名，不是「最值得买的股票」。

### 我的组合（My Portfolio）

在页面里直接添加你的持仓（Ticker 或名称），可选填权重；也可以删除持仓。
保存后下次打开自动载入。系统会对称展示每只股票的事实：谁增持、谁减持、谁退出、
重复活动、数据新旧、身份质量。它不会说「机构支持你的持仓」——它只给事实。

### 方法论与限制（Methodology）

用大白话解释 13F 是什么、每个动作是什么意思、以及为什么这不是股票推荐。

## 三、怎么更新最新 SEC 数据

**第 1 步**：确认看板已关闭（或保持开着也没关系，但建议先关闭）。

**第 2 步**：双击文件 **`UPDATE_13F_DATA.bat`**。

它会：

1. 从 SEC 官网下载你跟踪的 29 家机构的最新 13F 原始文件；
2. 重新生成本地数据库；
3. 重新计算持仓变化；
4. 给出成功/失败提示。

更新可能需要几分钟，需要联网。**不要中途关掉黑色窗口。**

**更新成功时你会看到：**

```
Update OK. filings=... holdings=... raw_added=...
```

**更新失败时你会看到：**

```
Update failed. Existing dashboard data remains available.
See log: ...\data\last_update.log
```

失败不会破坏你现有的看板数据；你仍然可以继续打开看板查看旧数据。

## 四、打不开怎么办（简单排查）

1. **双击后黑窗口一闪而过**：通常是 Python 没装或不在 PATH。
   先安装 Python 3.11+，再看 README_USER.md 的「第一次使用前」。
2. **浏览器没自动打开**：手动在浏览器地址栏输入 `http://localhost:8501`。
3. **页面报「数据库不存在」**：先运行一次 `UPDATE_13F_DATA.bat` 建立数据。
4. **端口被占用**：运行 `STOP_13F_DASHBOARD.bat` 后再启动。

---

## 五、怎么关闭看板

- 直接关闭那个黑色终端窗口；或者
- 双击 **`STOP_13F_DASHBOARD.bat`**（它只结束占用 8501 端口的看板进程）。

---

## 六、重要限制（请一定了解）

- 13F 只披露**多头持仓**，有最多 45 天延迟。
- 看不到空头、衍生品、对冲、精确买入时间、买入成本。
- 机构可能因保密申请未披露部分持仓，「当季没披露」不等于「不持有」。
- 未解析的证券身份会明确标出，系统不会猜测。
- 本看板**不是**选股推荐，也不产生买卖信号。
