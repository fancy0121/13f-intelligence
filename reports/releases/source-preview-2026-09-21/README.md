## 像使用图书馆一样使用
1. 先看总览日期和红黄提示：季度持仓不是今天的交易。
2. 在“机构 / Managers”输入机构名称并回车，查看其披露和变化。
3. 在“证券 / Securities”输入Ticker或CUSIP，核对匹配身份；多结果自己选择。
4. “我的组合”只填你自己的关注清单；空白时系统不编造示范持仓。
5. 把结果用于提出研究问题和追溯原件，不把它当成买卖指令。

安装、采集和启动入口见[项目README](../../../README.md)。仓库不附带私有数据库或原始缓存。公开模式缺少真实批准时会停止服务；不得关闭保护冒充上线。
