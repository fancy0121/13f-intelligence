## 这是什么

一套将SEC原始13F披露整理为机构、证券和季度变化的研究工具。
可以查披露持仓、比较股数和权重、按个人关注清单核查事实，并显示缺失或异常。
不是实时机构交易监控、荐股、券商接口或自动交易服务。

七个栏目：总览 / Overview、机构 / Managers、证券 / Securities、活动探索 / Activity、
我的组合 / My Portfolio、方法论与限制 / Methodology、研究观察 / Research Log。
中英文公司名用于阅读；证券身份依据可核验的原始编号和映射来源，不猜中文名或ticker。

## 给试用者的简单说明

维护者准备好本地数据和依赖后，打开看板：

1. **看日期和警告。** 报告季度不是今天；NOT_VALIDATED表示未完成正式验收。
2. **查机构。** 进入Managers，输入Berkshire并回车；查看披露持仓和前后变化。
3. **查证券。** 进入Securities，输入苹果或AAPL并回车；核对股类、代码和披露主体。
4. **看自己的清单。** My Portfolio里输入证券，必要时填权重；0.05表示5%。有多个候选时明确选对，系统不猜。
5. **提出下一步问题。** 股数增加而权重下降可以同时发生；不要把报告变化直接变成买卖指令。

当前冻结快照的Duquesne最新季度被隔离，应看到N/A和数据不足；这不是零持仓。
数据维护需要维护者执行采集、重建和验收。尚未完成无人值守生产更新，客户不用也不应该在页面批量请求SEC。
